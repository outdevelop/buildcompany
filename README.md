# Сайт ООО СК «ЭнергоСтройРесурс»

Одностраничный сайт строительной компании из Казани: поставка светотехники, кабельно-проводниковой продукции, электрощитового и климатического оборудования; электромонтаж, блочно-модульные котельные, вентиляция и кондиционирование, кровельные работы. Официальный дилер NITEOS, LumSmart, КАТЮША, НЕВА-ПРИНТ, ФОРЭНЕРДЖИ, дистрибьютор Меркор.

Сайт статический: HTML, CSS и JavaScript без сборки и зависимостей. Форму заявки обрабатывает `send.php`.

## Структура

```
index.html            главная страница
privacy.html          политика конфиденциальности (нужна по 152-ФЗ для формы)
send.php              обработчик формы: почта и/или Telegram
assets/css/style.css  стили
assets/js/main.js     меню, маска телефона, отправка формы
assets/img/favicon.svg
```

## Блоки главной страницы

1. **Первый экран**: слоган, кнопки, цифры (7 направлений, 20 заводов-партнёров, гарантия 5 лет).
2. **Направления**: поставка (светотехника, кабель, электрощитовое, климатическое оборудование) и монтаж (электромонтаж, котельные, вентиляция и кондиционирование, кровля).
3. **Объект в разрезе**: схема здания с позициями 1–9.
4. **Опыт**: объекты команды по четырём направлениям.
5. **Дилерство**: официальные дилерства, сертификаты (`assets/img/certs/`), список поставщиков.
6. **Как мы работаем**, **О компании**, **Частые вопросы**.
7. **Заявка и контакты**: телефоны, почта, адрес, реквизиты.

## Что проверить перед запуском

- В материалах встречаются три варианта основного телефона: +7 (995) 368-07-21 (листовка, письмо-предложение), +7 (995) 368-07-22 (бланк письма), +7 (995) 369-07-22 (карточка предприятия). На сайте стоит 368-07-21 — проверьте.
- В `send.php` укажите `$FROM_EMAIL` на домене сайта.
- Логотип — оригинальный, вырезан из скана карточки предприятия (`assets/img/logo.png`). Если есть исходный файл логотипа лучшего качества, замените этот PNG.
- Сертификат NITEOS показан текстом (номер договора и срок): исходный файл — шаблон .docx. Если пришлёте его в PDF или JPG, добавлю картинку.

## Форма заявки

`send.php` отправляет заявку на почту через `mail()` и, если заполнены настройки, дублирует её в Telegram. Настройки в начале файла:

```php
$TO_EMAIL   = 'energostroy2026@mail.ru'; // куда приходят заявки
$FROM_EMAIL = 'no-reply@example.ru';  // отправитель, лучше на домене сайта
$TELEGRAM_BOT_TOKEN = '';             // токен бота от @BotFather
$TELEGRAM_CHAT_ID   = '';             // ID чата или группы
```

Нужен хостинг с PHP 7.4 или новее (подходит любой обычный виртуальный хостинг). От ботов защищает скрытое поле-ловушка.

Если PHP нет (например, GitHub Pages), укажите в `assets/js/main.js` адрес другого обработчика в `FORM_ENDPOINT`, который принимает `multipart/form-data` и отвечает JSON `{"ok": true}`. Пустая строка включает демо-режим: форма проверяет поля, но ничего не отправляет.

## Локальный просмотр

```bash
php -S localhost:8080
```

и откройте http://localhost:8080. Без PHP можно открыть `index.html` в браузере, но форма тогда не отправится.

## Оформление

- Шрифты Google Fonts: **Tektur** (заголовки), **Golos Text** (текст), **JetBrains Mono** (подписи, маркировки, характеристики).
- Цвета заданы переменными в начале `assets/css/style.css`: графитовый `--ink`, медный акцент `--copper`, светлый «бетон» `--paper` / `--concrete`.
- Полоса из пяти цветов под первым экраном повторяет цвета жил кабеля: L1 коричневый, L2 чёрный, L3 серый, N синий, PE жёлто-зелёный.
