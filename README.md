# Сайт компании «ЭнергоМонтаж»

Одностраничный сайт компании, которая поставляет и монтирует электро- и энергооборудование, светодиодную и кабельную продукцию (как официальный дилер), а также монтирует зенитные фонари, люки дымоудаления и кровлю.

Сайт статический: HTML, CSS и JavaScript без сборки и зависимостей. Форму заявки обрабатывает `send.php`.

## Структура

```
index.html            главная страница
privacy.html          политика конфиденциальности (нужна по 152-ФЗ для формы)
send.php              обработчик формы: почта и/или Telegram
assets/css/style.css  стили
assets/js/main.js     меню, маска телефона, отправка формы
assets/img/favicon.svg
```

## Блоки главной страницы

1. **Первый экран**: заголовок, кнопки, цифры и разрез кабеля ВВГнг(А)-LS 5×16 с выносками.
2. **Направления**: поставка (электрооборудование, энергооборудование, LED, кабель) и монтаж (электромонтаж, зенитные фонари, люки дымоудаления, кровля).
3. **Объект в разрезе**: схема здания с позициями 1–8, от КТП до кровли.
4. **Дилерство**: преимущества и сетка логотипов производителей.
5. **Как работаем**: пять шагов.
6. **Почему удобно с нами** и типы объектов.
7. **Частые вопросы**.
8. **Заявка и контакты**: форма с выбором направлений.

Всё, что ниже, сейчас заглушка:

| Что | Где |

| Телефон `+7 (000) 000-00-00` и `tel:+70000000000` | `index.html` (шапка, мобильное меню, контакты, подвал, сообщение после отправки), `assets/js/main.js` (текст ошибки), `privacy.html` |

### Логотипы партнёров

Положите файлы в `assets/img/partners/` и замените в каждой карточке:

```html
<span class="partner__logo">логотип</span>
```

на

```html
<span class="partner__logo"><img src="assets/img/partners/brand.svg" alt="Название бренда"></span>
```

Лучше всего подходят SVG или PNG на прозрачном фоне. Высота логотипа ограничена 40 px.

## Форма заявки

`send.php` отправляет заявку на почту через `mail()` и, если заполнены настройки, дублирует её в Telegram. Настройки в начале файла:

```php
$TO_EMAIL   = 'info@example.ru';      // куда приходят заявки
$FROM_EMAIL = 'no-reply@example.ru';  // отправитель, лучше на домене сайта
$TELEGRAM_BOT_TOKEN = '';             // токен бота от @BotFather
$TELEGRAM_CHAT_ID   = '';             // ID чата или группы
```

Нужен хостинг с PHP 7.4 или новее (подходит любой обычный виртуальный хостинг). От ботов защищает скрытое поле-ловушка.

Если PHP нет (например, GitHub Pages), укажите в `assets/js/main.js` адрес другого обработчика в `FORM_ENDPOINT`, который принимает `multipart/form-data` и отвечает JSON `{"ok": true}`. Пустая строка включает демо-режим: форма проверяет поля, но ничего не отправляет.

## Локальный просмотр

```bash
php -S localhost:8080
```

и откройте http://localhost:8080. Без PHP можно открыть `index.html` в браузере, но форма тогда не отправится.

## Оформление

- Шрифты Google Fonts: **Tektur** (заголовки), **Golos Text** (текст), **JetBrains Mono** (подписи, маркировки, характеристики).
- Цвета заданы переменными в начале `assets/css/style.css`: графитовый `--ink`, медный акцент `--copper`, светлый «бетон» `--paper` / `--concrete`.
- Полоса из пяти цветов под первым экраном повторяет цвета жил кабеля: L1 коричневый, L2 чёрный, L3 серый, N синий, PE жёлто-зелёный.
